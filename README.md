# SmartStock

**SmartStock** — это информационная система управления складом, спроектированная для малого и среднего бизнеса, интернет-магазинов и логистических компаний. Система сочетает интуитивно понятный интерфейс, гибкую настройку структуры склада, встроенную аналитику и элементы искусственного интеллекта для прогнозирования спроса и оптимизации запасов.

> **Репозиторий проекта:** [https://github.com/Kryanrd/SmartStock](https://github.com/Kryanrd/SmartStock)

## 🎯 О проекте

Современный рынок логистики требует от бизнеса скорости, точности и прогнозируемости. Однако многие предприятия малого и среднего звена по-прежнему используют устаревшие методы учёта — Excel-таблицы, бумажные журналы или перегруженные ERP-системы, которые сложно внедрить и сопровождать без ИТ-отдела.

**SmartStock** решает эти проблемы, предлагая доступную, гибкую и визуально понятную альтернативу. Система ориентирована на:

- **Онлайн-магазины** — точный учёт остатков и интеграция с каналами продаж.
- **Небольшие склады и логистические стартапы** — гибкая настройка структуры хранения.
- **Розничные магазины с собственными складами** — быстрый поиск товаров и управление остатками.
- **Стартапы без ИТ-отделов** — минимальный порог входа и простота освоения.

Проект разработан в рамках итоговой работы на Цифровой кафедре Тульского государственного университета (2025 г.).

## ✨ Ключевые возможности

| Модуль | Возможности |
|---|---|
| **Гибкая структура склада** | Настройка зон, рядов, полок и ячеек; привязка товаров к конкретным ячейкам хранения |<br>
| **Учёт и перемещение товаров** | Приёмка, перемещение по складу, списание, отслеживание истории операций |<br>
| **Поиск и фильтрация** | Поиск по названию, SKU, штрихкоду; фильтрация по категориям, остаткам, срокам поступления |<br>
| **Визуализация склада** | Интерактивная 3D-карта склада с подсветкой занятых и пустых ячеек; отображение маршрутов перемещения |<br>
| **Голосовой поиск с ИИ** | Запросы на естественном языке («Где лежит Honor 11 на 256GB?») с отображением ячейки на схеме |<br>
| **Прогнозирование и аналитика** | Прогноз спроса, рекомендации по пополнению запасов, отчёты и графики |<br>
| **Управление складами** | Поддержка нескольких складов с адресами и описаниями |<br>
| **Роли и доступ** | Разграничение прав для директора склада, менеджеров по приёмке/хранению/отгрузке и рабочих |

## 🏗 Архитектура системы

Система построена по трёхуровневой архитектуре:

```
┌─────────────────────────────────────────────┐
│                  Frontend                    │
│         React SPA + 3D-визуализация          │
│         Голосовой поиск + UI-панель          │
└─────────────────────┬───────────────────────┘
                      │ REST API
┌─────────────────────▼───────────────────────┐
│                  Backend                     │
│           Node.js + Express                  │
│     Бизнес-логика, аутентификация, API       │
└─────────────────────┬───────────────────────┘
                      │ SQL
┌─────────────────────▼───────────────────────┐
│                 PostgreSQL                   │
│   Склады · Товары · Ячейки · Транзакции      │
│   Конфигурация склада · Остатки · История    │
└─────────────────────────────────────────────┘
```

### Модель данных (ER-концепция)

Основные сущности базы данных:

- **warehouses** — склады (название, адрес, описание).
- **racks** — ряды (привязка к складу, координаты, размеры).
- **shelves** — полки (привязка к ряду, уровень, позиция).
- **products** — товары (название, категория, габариты, цвет, привязка к ячейке).
- **warehouse_configs** — конфигурация размеров склада (ширина, глубина, высота, количество рядов/колонок).
- **Транзакции** — история приёмки, перемещений и отгрузок.

> ER-диаграмма и схема базы данных доступны в документации проекта.

## 📐 Моделирование бизнес-процессов

В рамках аналитической части проекта были построены модели складских процессов в нотациях **IDEF0**, **ARIS** и **BPMN**. Они описывают полный цикл работы склада: приём товаров, хранение и отгрузку.

### Контекстная диаграмма IDEF0

Основные процессы склада:

1. **Приём товаров** — проверка документов, визуальный осмотр, контроль качества, регистрация в WMS.
2. **Хранение товаров** — определение оптимального места, мониторинг запасов, инвентаризация.
3. **Отгрузка товаров** — комплектация заказов, подготовка транспортных документов, передача перевозчику.

### Дерево узлов (Node Tree)

```
Склад
├── Приём товаров
├── Хранение товаров
│   └── Складирование товаров
└── Отгрузка товаров
    ├── Подготовка транспортных документов
    └── Комплектация и отгрузка товаров
```

### BPMN-диаграммы

Детализированные BPMN-схемы для каждого процесса включают:

- **Приём товара** — проверка документов, осмотр, ветвление по качеству (возврат поставщику / размещение).
- **Хранение товара** — определение места, проверка лимитов, инвентаризация.
- **Отгрузка товара** — проверка заказа, комплектация, подготовка документов, передача транспортной компании.

Полные диаграммы (IDEF0, ARIS, BPMN) представлены в  документации проекта.

## 📊 Метрики и аналитика

SmartStock предоставляет инструменты для оценки эффективности складских операций:

| Метрика | Описание |
|---|---|
| **Точность учёта остатков** | Сопоставление фактических и системных данных |
| **Время поиска товара** | Среднее время нахождения товара сотрудником |
| **Процент ошибок комплектации** | Доля неверно собранных заказов |
| **Оборачиваемость товара** | Скорость продаж и пополнения по категориям |
| **Прогнозируемый дефицит / избыток** | На основе ML-моделей прогнозирования спроса |

В планах — внедрение дашбордов для оперативного мониторинга KPI и расширение модулей машинного обучения.
