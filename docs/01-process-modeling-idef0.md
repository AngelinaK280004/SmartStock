# Моделирование IDEF0

IDEF0 использована для верхнеуровневого описания функций склада и их взаимосвязей.

## Контекстная диаграмма
**Вход:** Товар, Документация товаров.
**Выход:** Доставка клиенту, Товар на складе.
**Управление:** Правила хранения товаров, Транспортные документы.
**Механизмы:** Рабочие склада, Менеджеры, Водители.

## Дерево узлов (Node Tree)
*   A0: Склад
    *   A1: Приём товаров
    *   A2: Хранение товаров
    *   A3: Отгрузка товаров

## Декомпозиция процессов
1. **Приём товаров (A1):** Проверка документов → Визуальный осмотр и контроль качества → Запись данных в систему.
2. **Хранение товаров (A2):** Определение места хранения → Мониторинг состояния запасов → Проведение периодических инвентаризаций.
3. **Отгрузка товаров (A3):** Получение заказов от клиентов → Комплектация и упаковка → Подготовка транспортных документов.
