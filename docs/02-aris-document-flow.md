# Моделирование ARIS: Документопотоки и обработка брака

ARIS-диаграмма позволила детально описать движение документов и логику обработки исключительных ситуаций.

## Ключевые события и документы
1. **Поступление товара:** Создается «Товарно-транспортная накладная».
2. **Проверка на дефекты:** 
   * Если дефекты обнаружены → создается «Акт о браке» → «Возврат товара».
   * Если дефектов нет → переход к проверке документов.
3. **Проверка документов:** Сверка с Удостоверениями, Спецификациями, Накладными, Сертификатами.
   * Если товар не соответствует документам → создается «Акт о несоответствии» → «Возврат товара».
   * Если соответствует → «Размещение товара на складе» и «Регистрация в базе данных».
4. **Отгрузка:** На основе заказа клиента происходит комплектация, затем оформляются финансовые бумаги (счета, консолидированные документы).
