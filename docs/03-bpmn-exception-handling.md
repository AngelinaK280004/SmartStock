# Моделирование BPMN: Логика процессов

BPMN-диаграммы детализируют логику выполнения операций и готовы к передаче в разработку.

## 1. Процесс «Приём товара» (Receiving)
*   **Стартовое событие:** Сообщение о поступлении.
*   **Действия:** Получение документов → Визуальный осмотр товара.
*   **Шлюзы (Gateways):**
    *   *Товар без брака?* (Да/Нет).
    *   *Документы соответствуют?* (Да/Нет).
*   **Ветка исключения:** Создать акт о несоответствии → Уведомить поставщика → Вернуть товар поставщику.

## 2. Процесс «Хранение товара» (Storage)
*   **Стартовое событие:** Сообщение о приеме товара.
*   **Действия:** Определить оптимальное место хранения → Разместить товар.
*   **Логика:** Если товара слишком много, система должна предложить перераспределение или отгрузку излишков. Проведение инвентаризации по расписанию.

## 3. Процесс «Отгрузка товара» (Shipping)
*   **Стартовое событие:** Получение заказа от клиента.
*   **Действия:** Проверка наличия → Комплектация и упаковка.
*   **Шлюзы:** *Товар в наличии?* (Да/Нет).
*   **Ветка исключения:** Если товара нет → Перенос заказа или отмена.

## Обработка ошибок в BPMN
В схемах явно используются промежуточные события (Message) для уведомления поставщика и клиента, а также эндпоинты для успешного и неуспешного завершения процесса.
