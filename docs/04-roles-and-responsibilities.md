# Организационная структура и роли

На основе анализа предметной области выделены следующие роли, которые в будущем лягут в основу матрицы доступа (RBAC) WMS.

| Роль | Зона ответственности | Связанные процессы |
|---|---|---|
| **Директор склада** | Стратегическое управление, бюджетирование, взаимодействие с другими подразделениями. | Общее управление (A0) |
| **Менеджер по приёмке** | Контроль процесса приёмки, проверка качества и документов, составление актов о браке. | Приём товаров (A1) |
| **Менеджер по хранению** | Организация хранения, управление запасами, проведение инвентаризаций. | Хранение (A2) |
| **Менеджер по отгрузке** | Организация отгрузки, взаимодействие с клиентами, контроль сроков доставки. | Отгрузка (A3) |
| **Рабочие склада** | Выполнение физических операций: разгрузка, перемещение, комплектация, упаковка. | A1, A2, A3 |
| **Водители** | Транспортировка товаров. | Отгрузка (A3) |

## Аналитический вывод
Система должна поддерживать как минимум 4 уровня доступа (Директор, Менеджер, Рабочий, Водитель). Например, рабочий не должен иметь права изменять документы, а менеджер по приёмке — не должен иметь доступ к финансовым документам отгрузки.
