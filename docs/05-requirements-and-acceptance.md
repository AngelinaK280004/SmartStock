# Требования и критерии приёмки

На основе моделей бизнес-процессов (IDEF0, ARIS, BPMN) сформированы требования к WMS.

## Функциональные требования (FR)

| ID | Требование | Приоритет |
|---|---|---|
| **FR-01** | Система должна поддерживать проверку документов при приёмке (ТТН, сертификаты). | Must |
| **FR-02** | Система должна позволять фиксировать дефекты и формировать «Акт о браке». | Must |
| **FR-03** | Система должна вести учет доступного пространства на складе. | Must |
| **FR-04** | Система должна поддерживать проведение инвентаризации (плановой и внеплановой). | Must |
| **FR-05** | Система должна формировать «Акт о несоответствии» при расхождении данных. | Must |
| **FR-06** | Система должна отслеживать статус заказа клиента (в наличии / нет в наличии). | Should |

## Критерии приёмки (Gherkin)

### Сценарий: Приёмка товара с дефектом
```gherkin
Feature: Приёмка товара
  Scenario: Обнаружение брака при визуальном осмотре
    Given поставщик привез товар
    When менеджер по приёмке проводит визуальный осмотр
    And обнаруживает дефект
    Then система должна предложить создать "Акт о браке"
    And после создания акта статус товара меняется на "Возврат поставщику"
    And товар не размещается на складе
